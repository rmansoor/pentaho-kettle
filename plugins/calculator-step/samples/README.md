# Calculator Step Samples

This directory contains sample files and documentation for the Calculator step.

## Structure

- `transformations/` - Sample transformation files (.ktr) demonstrating the Calculator step
- `data/` - Sample data files used by the transformations
- `documentation/` - Additional documentation and examples

## Usage

Import the .ktr files into Pentaho Data Integration (Spoon) to see the Calculator step in action.

## Requirements

- Pentaho Data Integration 9.0 or later
- Calculator step plugin installed

## Available Samples

- `basic_calculator_example.ktr` - Basic mathematical calculations
- `date_calculations.ktr` - Date-related calculations
- `string_functions.ktr` - String manipulation functions
- `advanced_calculations.ktr` - Complex mathematical operations
