#  Step Samples

This directory contains sample files and documentation for the  step.

## Structure

- `transformations/` - Sample transformation files (.ktr) demonstrating the  step
- `data/` - Sample data files used by the transformations

## Usage

Import the .ktr files into Pentaho Data Integration (Spoon) to see the  step in action.

## Requirements

- Pentaho Data Integration 9.0 or later
-  step plugin installed
